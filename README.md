# OmegaSub — Site oficial

Site estático de apresentação do **OmegaSub — Legendas PT-BR**, preparado para o repositório [`OmegaSub/omegasub.github.io`](https://github.com/OmegaSub/omegasub.github.io).

## Publicação no GitHub Pages

1. Envie **todos os arquivos desta pasta** para a raiz do repositório `OmegaSub/omegasub.github.io` (incluindo a pasta `assets`).
2. Faça o commit na branch `main`.
3. Abra **Settings → Pages** no repositório.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione **main** e **/(root)**, depois clique em **Save**.
6. Aguarde a publicação e acesse **https://omegasub.github.io/**.

Se o GitHub já tiver ativado Pages automaticamente, basta conferir a URL em Settings → Pages.

## Arquivos

- `index.html`: conteúdo e links.
- `style.css`: visual responsivo preto/vermelho.
- `script.js`: atualização automática do ano no rodapé.
- `assets/omegasub-logo.png`: identidade visual OmegaSub.
- `assets/favicon.png`: ícone da aba do navegador.
- `.nojekyll`: publicação estática sem processamento Jekyll.

## Links

Os botões de download apontam para a página da **última Release** do projeto, sem inventar nomes de arquivos que podem mudar entre versões. Se necessário, atualize as URLs no `index.html`.

Repositório do aplicativo: https://github.com/JulianoHOmega/OmegaSub-Legendas-PTBR

Este site **não altera o código dos executáveis Windows ou Linux** e não precisa de Python, banco de dados ou servidor próprio.
